# 安全偵測的限制（請 README、首頁、使用者測試同意書引用）

## 一句話版（可直接放進同意文字）
本遊戲**不能偵測多數危機表達**，也不是心理或危機介入工具。如果你正感到不好受、被威脅或被騙，請直接使用畫面上的求助入口，
或撥 1925（安心專線）、165（反詐騙）、113（保護專線）。使用者測試全程應有真人在場。

## 實測數字（以質疑者獨立盲測為準）
- 質疑者第 4 輪對全新語料（202 句）的量測：該終局的句子**召回約 27%**，其中**第一人稱自傷只有 10/62，約 16%**；
  **誤終局約 10%**（日常、誇飾、入戲語句被當成危機）。
- `heuristic_classifier` 啟用後，在同一批語料上**沒有差異**；它預設也是關閉的，mock 模式只靠規則。
- 後端 A 自己評的「49%」（未調整前）與「98%」（調整後）是在**自己寫並看過的句子**上量的，是調整過的上界，**不能當作真實表現**，
  之前文件寫的「大約一半到八成」是不實的，已刪除。每換一批新語料，召回大約回到 20–30%。

## 為什麼
- 現行偵測是關鍵字與句型規則（自傷、暴力跟蹤、現實詐騙／性勒索、疑似未成年、要求暫停、詢問是不是 AI）。規則只對「寫過的說法」有效，
  對隱晦黑話、台語、中英混用、長句脈絡幾乎沒有泛化。繼續堆詞庫只會重複過擬合。
- 誤判有兩種：漏判（有危機沒攔到）與誤終局（誇飾、第三人稱、研究主題、遊戲內台詞被當危機）。目前對第三人稱、小說、誇飾降為「溫和提醒」，
  但仍會有誤終局，也仍會漏判。

## 因此（流程，而不是靠程式）
1. 使用者測試前向參與者說明上面那段話；測試全程有人在場、可隨時停止。
2. 🆘 求助入口在所有畫面常駐，並顯示 1925／165／113。
3. 第二道網（LLM 分類器）已決定啟用（2026-11-09）：Claude 模式下預設開啟（`GAME_SAFETY_LLM=0` 可關），同意文字 v2 已說明外部傳輸。
   **尚未用真 API 實測，也沒有盲測數字，不得假設有效。** mock 模式下不適用。
4. 驗收只看盲測：由質疑者／研究組每輪重寫、不進 repo 的語料；不得以 repo 內測試全綠宣稱 safety 已解。
