## safety.py（Q1、Q14）
- 先 normalize：NFKC 全半形、小寫、移除所有空白／標點／符號／emoji。「自 殺」「自.殺」「Ｋｉｌｌ　ｍｙｓｅｌｆ」都能抓到。

- 排除慣用語：想死你、不想死、不想活在這種關係裡、跳樓大拍賣、你去死（對 NPC 罵人）。
- 真實暴力跟蹤脅迫（含「我被我男友打」這種夾字句型）、被要求匯款買點數、裸照／私密照／性勒索、已被騙、疑似未成年（歲數 <18、國中小、國二、高一、「我14」）。

- 介面：新增 `assess()`（完整判定）、`respond()`；`check()` 向下相容，只對需終局的類別回傳；`response()` 保留舊欄位，新增 `severity`、`ends_session`。資源統一 1925／165／113。
- 嚴重度：high（自傷、暴力、詐騙）、medium（未成年、pause、too_painful、model）、low（降級提醒）、info（ai_identity）。

## 第 3 輪：safety 第三人稱誤判修正
- 根因：暴力規則「他.{0,6}殺我」在正規化（去標點）後，跨字吃到「他想自殺我不知道怎麼辦」裡的「自殺我」的「殺我」，被判成 real_violence / first_person（模式內含「我」，略過第三人稱降級），因此終局。與「說」「不知道怎麼辦」無關。
- 修正：`殺我`、`殺了我` 加 `(?<!自)`，不再從「自殺」取字。
- 新增：第三人稱降級後若緊接「我也是／我也想／我跟他一樣／我自己也…」，改回第一人稱高風險（「我朋友也想死，我也是」、「我朋友想自殺，我也想」維持 high）。
- 漏判修補：「朋友／同學／客服叫我匯款」納入 real_scam 主詞。
- 掃描 26 句第三人稱／求助他人／混合句型（朋友、同學、家人、劇情）：自傷、暴力、性勒索的第三人稱皆為 low，第一人稱混合句皆為 high。已知取捨：「朋友被騙了三萬」「弟弟被同學打」不觸發任何類別（第三人稱且非危機）。
- tests/test_safety.py 新增 16 句 low、8 句混合 high、1 組自殺非暴力回歸。

## 第 6 輪：承認 safety 詞庫泛化差，補結構性規則與第二道網介面
前提：第 5 輪的「0 不符」是針對測試集修的，質疑者全新 218 句漏 80%（該終局 92 句漏 74，自傷 1/46）。本輪起不再宣稱 safety 已解。

### 做了什麼
- `safety.set_classifier(fn)` / `get_classifier()`：可插拔第二道分類器，預設關閉；規則沒觸發或只有 low 時才呼叫；例外與壞格式一律當沒事。附 `heuristic_classifier`（第一人稱 + 多個絕望線索 → self_harm/low，只提醒，不完整）。
- 結構性規則：自傷改成「意圖詞（想、欲、打算、考慮…）+ 填充字 + 死亡／消失／結束詞」的組合，加上狀態（活不下去／活袂落去／不想再撐）、負擔感、告別與準備手段（遺書、囤藥、買炭、託付寵物）、委婉說法（長眠、永遠休息、下線人生）、台語（欲死、袂堪得活）、英文（wish I was dead、don't want to be alive、unalive、no reason to go on…）。暴力：任意主詞 + 暴力動詞 + 我、「把我推…」、尾隨、威脅要殺我、不讓我出門。詐騙：安全帳戶、保證金／手續費、帶單、網戀借錢、私密影片威脅、任何人「叫我去買點數」。未成年：上國一／現在高一／小學五年級／未滿18。pause、ai_identity 也補了句型。
- 誤判修正：入戲轉帳（句中含「你」的「我匯了…到你的帳戶」、「買了點數拍序號給你」）不再是現實詐騙；「被他打槍了」不再算被打；「我社死了好想消失」「社恐的我想消失在聚會裡」「被老師點名好想消失」降為 low；「工作壓力大到快撐不住了」降為 low；「我不想活在別人的期待裡」不觸發；否定前綴補上「不」「別」。
- scoring：入戲轉帳 classify 為 brain 並抽金額（記為匯款事件）；Q51 禮貌自然回覆（好啊、嗯嗯我了解、謝謝你）改為 neutral，不再 brain；無條件讓步（沒關係、都可以）仍 brain；行為分新增「對無紅旗訊息做中性回應」正向項（NORMAL_CREDIT）。順手修「對不起是我的錯」被「對不起」裡的「不」當成否定。
- coach：`interject(..., has_red_flag=None)`；`False` 時拒絕不稱讚，回中性提示（TEMPLATES["refuse_clean"]，每尺度 3 句）。
- 文件：docs/safety_limits.md（請 README、首頁、同意書引用）、docs/backend_a_requests.md（B 的接線需求）。
