查證日期：2026-11-08。方法：以 WebSearch 查詢，下列來源是**搜尋結果實際出現**的連結。限制：我只看到搜尋工具回傳的摘要，**沒有逐頁讀完全文**；標示「待確認」者表示需要組員點開原文核對後才能正式引用（尤其是統計數字與引文）。查不到的地方我明說，沒有補編造。

## 1. 「戀愛腦」的定義

### 1.1 目前查到的結論
- 「戀愛腦」是**流行用語，不是正式心理學或精神醫學診斷**。這點在多個來源一致。
- 常見描述：戀愛時把情緒、注意力和生活重心過度放在對方身上，甚至放棄自我；與「過度依附」「自我價值寄託在伴侶」相關。
- **我沒有查到**專門以「戀愛腦」為名、且有嚴謹定義或量表的學術論文（中文搜尋只回傳媒體與生活網站）。這是目前的缺口，建議下一步用 Google Scholar／華藝／台灣博碩士論文網以「戀愛腦」「情感依附」「浪漫信念」搜尋。

### 1.4 建議的專題「操作型定義」（需小組討論）
在找到更好依據前，建議在產品中這樣寫，並標明是工作定義：

> 「戀愛腦」是口語，非診斷。在本遊戲中指：在親密關係（含網路認識的對象）裡，因期待、依附或情緒壓力而忽略、合理化明顯的風險訊號（紅旗），甚至做出損及自身界線或財產的決定。

優點：把焦點從「人格缺陷」轉到「行為與情境」，與倫理建議一致，也直接對應紅旗系統。

### 1.5 台灣詐騙現況（用於「為何要做」的背景）
來源為媒體轉述 165 打詐儀表板（內政部警政署），**我沒有取得原始報表**，引用前請至 165 儀表板核對。

- 2025 年全年（媒體報導）：假投資財損約 451 億元（50.57%）；假交友（投資財產）財損約 160 億元（18.02%）；假交友（徵婚詐財）約 25 億元（2.89%）。
  - 來源：https://news.tvbs.com.tw/local/3100279 、 https://udn.com/news/story/124490/8948666 、 https://newtalk.tw/news/view/2025-08-11/987098 （搜尋結果列出；數字出自搜尋摘要，待逐篇核對）
- 趨勢科技報告：愛情詐騙為耗時數週的「養套殺」，73% 簡訊詐騙受害者曾被要求改到 LINE 等平台（民間資安公司分析，非官方統計）。 https://www.inside.com.tw/article/40489-trend-micro-2026 （待確認）
- 啟示：財損主力是「交友 + 投資」混合手法，這與「愛情騙子」人格的紅旗（fast_intimacy -> small_invest -> withdraw_fee）高度吻合，建議把該人格當優先人格；也支持老師說的「分類聚焦前三／前五名」。

## 2. 「怎麼讓使用者聽進去」的依據

### 2.1 預先提示／遊戲式教學（inoculation）
- Roozenbeek & van der Linden（2019）Palgrave Communications，「Bad News」遊戲，讓玩家扮演造假者學習假新聞手法，降低對假新聞的相信度；摘要稱可信度平均降低約 21%（各來源數字略有出入），且不影響對真新聞的評價。樣本約 15,000（遊戲內調查，自選樣本，非隨機）。
  - 連結（搜尋結果）： https://www.cam.ac.uk/research/news/fake-news-vaccine-works-pre-bunk-game-reduces-susceptibility-to-disinformation ；論文 DOI（來源引用，待核對）：10.1057/s41599-019-0279-9
  - 限制：領域是假新聞，不是愛情詐騙；遷移性需自己驗證。
- 愛情詐騙嚴肅遊戲隨機對照試驗（預印本，尚未同儕審查）：英國成人 4,201 人，三組（遊戲／文字介入／對照）；4 週後正確回應率遊戲組 75%、文字組 71%、對照組 70%，且沒有讓人對正常訊息也變多疑。
  - 連結： https://preprints.jmir.org/preprint/97871 、新聞稿 https://www.eurekalert.org/news-releases/979304
  - 質性報告（Ofcom）： https://www.ofcom.org.uk/siteassets/resources/documents/online-safety/research-statistics-and-data/romance-fraud-research/harnessing-the-power-of-serious-games-to-protectpeople-against-romance-scams-qualitative-findings.pdf ；其中指出「紅旗」概念可作為遊玩動機。
  - 這與本專題最接近，效果差距小（75 vs 70），提醒我們別宣稱「大幅提升」。這些數字來自搜尋摘要，待讀全文確認。
- 設計意涵：遊戲式、有回饋、並同時練習「正常訊息不要誤判」（對應我們的 precision 指標）。

### 2.2 羞愧與語氣
- Bitdefender 的建議文章指出：直白說「這明顯是詐騙」會讓人覺得被暴露，更難重新思考，羞愧常讓人更深陷否認；建議站在對方這邊、降低羞愧才能打開對話。 https://www.bitdefender.com/en-gb/blog/hotforsecurity/how-to-talk-to-romance-scam-victim
- AARP：詐騙受害後常見強烈羞愧與自責，影響心理健康。 https://www.aarp.org/money/scams-fraud/mental-health-impact/
- Georgia State 研究報導稱受害者的心理創傷類似家暴受害者（媒體轉述，**我標為需核對原論文**）。 https://www.futurity.org/dating-apps-scams-romance-fraud-2873302/
- **缺口**：我沒有找到任何比較「嚴厲 vs 溫和」語氣在 AI 或遊戲介面對防詐效果的實證研究。以上為給家人／助人者的建議，套用到遊戲是**推論**。這正好是我們使用者測試要回答的問題（RQ3），可以當作貢獻點。

## 3. 罵人尺度（溫柔／毒舌／地獄）設計依據

### 3.1 目前的實作（讀自 `engine/coach.py`）
- 原則：每句罵都引用對方原話與紅旗，罵「行為」不是「人」。
- 1 溫柔提醒、2 毒舌、3 地獄；地獄含「恭喜，X 元成功捐給詐騙集團」等語句，結算低分時有「提款機兼情緒垃圾桶」。

### 3.2 設計建議（依據 + 推論）

| 尺度 | 適用 | 建議語氣 | 風險 |
|---|---|---|---|
| 溫柔 | 預設；有受騙／暈船經驗；情緒不穩 | 先肯定感受，再指出手法，問句式（「你有注意到...嗎？」） | 可能太軟、無感 |
| 毒舌 | 想被激勵的玩家 | 幽默、對事不對人、有憑據 | 被讀成嘲笑；幽默因人而異 |
| 地獄 | 主動選擇、明確同意 | 誇張戲劇化，像損友，但不攻擊人格 | 觸發羞愧、再度創傷；語句「你是提款機」已偏向人身貶低 |

依據：2.2 的羞愧文獻（推論）、遊戲課堂 10/20 討論「罵人尺度參考」。原則如下：
1. 預設溫柔；毒舌／地獄需玩家主動切換，地獄切換時顯示一次說明（「這是戲劇化模擬，不代表你真的蠢」）。
2. 永遠罵行為，不罵人；避免「蠢、笨、提款機」等人格貶低詞，改成「這招很有效，幾乎所有人都會被打到」。
3. 結算低分不要嘲笑，提供「下一步」。
4. 提供一鍵靜音教練、隨時調整尺度。
5. 危機字詞（自傷、真實被騙正在進行）時，立刻切換為溫和模式並顯示 1925／165／113（`engine/safety.py` 已有偵測，要測其召回率）。
6. 以使用者測試確認：不同背景者對三尺度的接受度（見 usability_test_script.md T4）。

### 3.3 找不到的部分（明說）
- 找不到「罵人尺度」的專屬學術標準或業界規範。
- 可再查方向：Duolingo 等應用的「毒舌／鼓勵」通知風格案例、動機式晤談（motivational interviewing）的非對抗原則、self-compassion 與改變意願研究、「roast」文化與冒犯感的人機互動研究。**以上是檢索建議，不是已查證結果。**

## 4. 倫理風險清單

| 風險 | 說明 | 緩解 |
|---|---|---|
| 二次傷害／羞愧 | 有受騙經驗者被罵 | 預設溫柔、同意、靜音、避免人格貶低 |
| 責怪受害者 | 「戀愛腦」標籤暗示是受害者的錯 | 文案強調「詐騙者很專業」；覆盤對準手法 |
| 刻板印象 | 以性別／年齡標示受害者 | NPC 男女皆可；避免「某性別比較笨」語句 |
| 偏見／污名 | 迴避型、焦慮型等依附風格被當壞人 | 說明這是互動模式，不是診斷；不暗示可診斷使用者 |
| 偽專業 | 看起來像心理測驗／診斷 | 小測驗加免責聲明：娛樂與教育用途，非診斷 |
| 資料隱私 | 存檔 `saves/<玩家ID>.json` 含私密對話 | 匿名 ID、告知、可刪除；LLM 傳輸前去識別化 |
| 使用者在遊戲中輸入真實事件 | 可能是真實求助 | 危機偵測 + 求助資源，不給醫療／法律建議 |
| LLM 生成不當內容 | 地獄尺度失控 | 輸出過濾、固定句式範本、人工抽查 |
| 過度自信 | 玩完覺得自己不會被騙 | 說明遊戲是練習，不保證；提供現實檢核 |
| 暈船互助會的安全 | 詐騙者潛入、他人曝光個資 | 匿名、審核、禁止留聯絡方式、檢舉機制 |
